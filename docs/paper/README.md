# ISSW 2026 Paper

"Forecasting Avalanches in Data-Sparse Central Asia Using Snowpack and Weather Modeling with Avalanche Observations" — extended abstract for ISSW 2026, Whistler.

Based on the ISSW LaTeX template (originally by JT Fischer, Innsbruck 2018 organizing committee), which aims to align with the official Word template.

## Files

- `central_asia_avalanche_issw2026.tex` — paper source
- `central_asia_avalanche_issw2026.pdf` — compiled output
- `references.bib` — bibliography database
- `issw.cls` — ISSW LaTeX class (rewritten in 2026 for WCAG accessibility)
- `figures/` — figure PNGs, regenerated by `src/main.py` (see `docs/paper/figures` sources in `output/`)

## Compiling

Requires `lualatex` and `biber` (e.g. via a TeX Live install):

```bash
lualatex -interaction=nonstopmode central_asia_avalanche_issw2026.tex
biber central_asia_avalanche_issw2026
lualatex -interaction=nonstopmode central_asia_avalanche_issw2026.tex
lualatex -interaction=nonstopmode central_asia_avalanche_issw2026.tex
```
